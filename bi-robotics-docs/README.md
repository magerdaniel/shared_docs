# BI-Robotics -- documents

BI-Robotics defines BI content (KPIs, tables, dashboards, filters) once, tool-agnostically, lets
AI agents build it in BI tools (GoodData, Cube, Power BI, Superset), and measures every number the
tools return against an independent oracle (OrionBelt). Version 0.0.5.

The same dashboard ("Star Books & Music", five pages), built by AI agents from one tool-agnostic
definition in three BI tools. All business figures are synthetic; books, music, publishers, labels
and countries are real (Wikidata).
